# Triage labels

| Vai trò | Giá trị Status | Ý nghĩa |
| --- | --- | --- |
| needs-triage | needs-triage | Cần đánh giá |
| needs-info | needs-info | Chờ thêm thông tin |
| ready-for-agent | ready-for-agent | Đủ đặc tả để agent thực hiện |
| ready-for-human | ready-for-human | Cần người thực hiện |
| wontfix | wontfix | Không triển khai |

Các skill dùng đúng giá trị trên khi ghi trạng thái triage
vào dòng `Status:` của ticket Markdown.
